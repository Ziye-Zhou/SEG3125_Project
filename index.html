About Me

My name is Ziye Zhou. I am currently learning UI design, visual communication, and web development. I am also passionate about powerlifting, especially the process of improving the squat, bench press, and deadlift through consistent practice.

This portfolio uses a fitness-inspired theme because powerlifting reflects many qualities that I also want to bring into my design work: structure, focus, patience, and continuous improvement. Through this portfolio, I want to present my UI design learning process in a way that feels strong, organized, and personal.

How I Work

1. Review Client Materials

I start by reviewing the materials provided by the client, such as required text, logos, images, icons, or vector files. I also ask questions about the expected style, size, colors, and overall visual direction.

2. Brainstorm Ideas

Next, I search for inspiration online and explore possible visual ideas, design elements, fonts, layouts, and references. This step helps me brainstorm different creative directions before starting the design.

3. Create a Layout Plan

Then, I create a rough sketch or layout plan to decide where each element should be placed. This helps me organize the page structure, visual hierarchy, spacing, and balance before building the first version.

4. Design, Feedback, and Revise

Finally, I create the first version of the design and ask for feedback. Based on the comments I receive, I revise the design by improving details such as color, typography, alignment, spacing, and clarity.
